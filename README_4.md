# Company Registration Guide (South Africa)

An interactive, step-by-step guide for registering a private company **(Pty) Ltd** on CIPC's BizPortal and getting it tender-ready (SARS, CSD, B-BBEE).

## Files

| File | What it is |
|---|---|
| `index.html` | **Start Your Company Quest**: the general guide for anyone. 27 steps over 8 levels, a name checker, a bank cost calculator, a quiz and a "My references" box. |
| `thesoro-quest.html` | **The Thesoro Company Quest**: the personal tracker used to register Munonde Thesoro Group (Pty) Ltd. Contains its reference numbers, so keep this repository private if you keep this file. |

## How to use

Open either file in a browser. Progress ticks and references are saved in that browser only.

The **AI helper** (questions and screenshot uploads) works only when the guide is opened on Claude (claude.ai) by a signed-in viewer. In a plain browser or on GitHub Pages the chat is hidden and everything else works.

## Notes

Fees and rules were checked in November 2026 (name reservation R50, registration R125, free EME B-BBEE certificate, bank fees from each bank's 2026 price guide). CIPC, SARS and banks change these, so confirm on their sites. General information, not legal or tax advice.
